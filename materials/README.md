# Course material

Everything in this folder is what the agent is allowed to teach from.

- Supported files: `.pdf` (slides, one chunk per page), `.md`, `.txt`.
- Put the real Linear Algebra slides and notes in `linear_algebra/` and delete `LA_sample_notes.md`.
- Restart the app (or press "Rerun"): the index rebuilds automatically.
- Then update `data/course_map.json` so topic titles match your course and the ML calendar is the real one.

Scanned PDFs with no text layer will not work; export slides as text PDFs.
